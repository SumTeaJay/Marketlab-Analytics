# Сравнение двух структур рынка: монополии и совершенной конкуренции

## О чем документ
Файл представляет собой обобщение двух отчетов. Он содержит выводы, сделанные на основе примененной экономической модели, произведенных расчетов и графиков.

Главная цель - продемонстрировать различие режимов на основе нескольких показателей.

# Ключевой вопрос
Как различаются цена, выпуск и общественное благосостояние при монополии и совершенной конкуренции на рынках с одинаковыми параметрами спроса и издержек?

# Экономическая модель
- Обратный спрос имеет вид \(P=a-bQ\);
- Предельные издержки постоянны;
- Налоги, субсидии и внешние эффекты отсутствуют;
- Для одного рынка параметры \(a\), \(b\) и \(MC\) одинаковы в обоих режимах;
- Данные искусственно сгенерированы.

## Ограничения
- Данные сгенерированы искусственно;
- Спрос линейный;
- Издержки постоянны;
- Нет стратегического взаимодействия фирм;
- Не проводятся статистические проверки гипотез;
- Нельзя делать эмпирические причинные выводы.

## Выводы
В сгенерированной выборке медианная цена при монополии выше конкурентной, а медианный выпуск ниже. Это означает, что монопольный режим ограничивает выпуск и позволяет продавать его по более высокой цене. Такой результат соответствует условиям \(MR=MC\) для монополии и \(P=MC\) для совершенной конкуренции. Однако данные являются искусственно сгенерированными и не подтверждают такое соотношение для реальных рынков без дополнительных данных.

Помимо этого, в сгенерированной выборке структура общественного благосостояния при совершенной конкуренции состоит только из излишка потребителя, когда же общественное благосостояние при монополии состоит из суммы излишков производителя и потребителя. Это означает, что только при монополии продавец имеет возможность зарабатывать. Такой результат соответствуют условию \(MC=const\). Если бы предельные издержки не были постоянными, такой вывод нельзя было бы сделать.
