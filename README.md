# Marketlab-Analytics
## Что это за проект?
Это программа, которая на основе искусственно созданных данных сравнивает две формы рыночной конкуренции: монополию и совершенную конкуренцию. Она генерирует графики, сводные таблицы и отчеты, на основе которых можно заметить разницу между рыночными моделями.

## Какую задачу решает проект?
Проект изначально создавался как учебный. Его цель - на основе множества наблюдений показать разницу между рыночными структурами, основанными на микроэкономике.

Для себя я создавал программу как способ погрузиться в аналитику и лучше понять все, что мне рассказывают в ВШЭ.

## Какие требования?
Python 3.14+

## Как установить?
Перейдите в папку, куда хотите установить проект, указав полный путь:
```bash
cd C:\Users\example
```

Клонируйте репозиторий:
```bash
git clone https://github.com/SumTeaJay/Marketlab-Analytics.git
```

Создайте виртуальное окружение:
```bash
python -m venv .venv
```

Активируйте его в PowerShell (или в любом другом приложении с терминалом):
```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости для разработки:
```bash
pip install -r requirements.txt
```

## Как работать с проектом?
Сама программа не требует ничего на вход. После установки для запуска проекта вы пишете следующую команду:
```bash
python pipeline.py
```

На выходе вы получите отчет, две таблицы и три графика. 

Отчет и таблицы находятся в data/report. Эти файлы содержат численные характеристики рынков при разных формах конкуренции. Графики находятся в data/graphs. Они показывают зависимость между разными параметрами рынка.

Хочу уточнить, что программа не генерирует конечные выводы. Она просто создает материал, который потом можно использовать для итогового анализа. 

В папке documentation находится файл, в котором на основе созданных данных сравниваются рыночные структуры.


## Структура
Весь проект логически можно разделить на несколько частей:
### Точка входа
- `pipeline.py` — основной скрипт, запускающий анализ

### Файлы для обучения
Проект - учебный. На нем я впервые пробовал себя как аналитика. 
Это все упражнения и выводы, которые я делал в ходе работы над проектом.
- `notes/` — общие впечатления от работы на неделе
- `experiments/` — скрипты и описание упражнений по дням.

### Данные для работы
Это все данные, которые создаются, очищаются и обрабатываются в виде графиков и отчетов.
- `data/raw/` — сгенерированные данные о рынках
- `data/processed/` — обработанные данные о рынках
- `data/audit/` — найденные ошибки в данных
- `data/calculated_data/` — модели рынков и их параметры
- `data/graphs/` — графики

### Этапы анализа
Это все файлы, которые как раз и запускают само приложение.
- `app/initialisation.py` — скрипт, содержащий все названия путей для файлов. Нужен для запуска на всех платформах.
- `app/generation.py` — скрипт генерации сырых данных.
- `app/preparation.py` — скрипт очищения сырых данных. Нужен для устранения потенциальных ошибок во время применения рыночных моделей.
- `app/calculation.py` — скрипт применения рыночных моделей. Он рассчитывает все показатели на основе которых будут сравниваться монополия и конкуренция.
- `app/validation.py` — скрипт проверки данных рассчитанных моделей
- `app/analysis.py` — скрипт генерации отчетов, графиков и сводных таблиц.

### Остальное
- `documentation/` — спецификация (описывает все ограничения проекта) и итоговый отчет, написанный от руки.
- `requirements.txt` — необходимые библиотеки для установки
