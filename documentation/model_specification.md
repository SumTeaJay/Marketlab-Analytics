# Цель
Сравнить влияние монополии и совершенной конкуренции на результаты участников и общественное благосостояние

# Контекст и описание задачи
Необходимо закрепить учебный материал на практических примерах и попробовать разные направления IT. Для этого создан MarketLab - это аналитический проект, анализирующий рынки с помощью микроэконономической модели.

## Что в модели является рынком?
Рынок - это совокупность параметров, формирующих предельные издержки, цену и предельную выручку.

## Какие параметры относятся к спросу, а какие — к издержкам?
К спросу относятся:
- `demand_intercept`
- `demand_slop`
- `quantity`
- `price`

К издержкам относится `marginal_cost`

## Какие данные являются входными, а какие вычисляемыми?
Входные данные:
- `demand_intercept`
- `demand_slop`
- `quantity`
- `marginal_cost`

Вычисляемые данные:
- `price`
- `marginal_revenue`
- равновесный выпуск
- равновесная цена
- излишки производителя и потребителя
- общественное благосостояние

## Какие величины должны различаться между режимами?
- равновесный выпуск
- равновесная цена
- излишки производителя и потребителя

## Какие величины обязаны оставаться одинаковыми?
- `price`
- `marginal_revenue`
- `marginal_cost`
- общественное благосостояние

## Что произойдёт, если издержки окажутся слишком высокими?
Надо сравнить с прибылью в случае закрытия - если издержки выше, удалить.

# Требования к данным
## Источники данных
- market_price.csv
Хранит параметры для расчета обратной функции спроса (P = a - b * Q)
- market_costs.csv
Хранит параметры предельных издержек

## Связанные ключи
Обе таблицы связаны по ключу `market_id`

## Вопросы о старых quantity и price
Генерируемые параметры quantity и price исключены из новой экономической модели. Их генерация и обработка сохранена, но они сами не будут учитываться.

# Логика расчета / обработки
1. Рассчитать равновесный выпуск для обоих случаев
2. Рассчитать равновесную цену для обоих случаев
3. Рассчитать излишек производителя для обоих случаев
4. Рассчитать излишек потребителя для обоих случаев
5. Рассчитать общественное благостостояние для обоих случаев

# Формат результата
Сравнительная таблица, в которой описаны параметры равновесного выпуска, равновесной цены, излишка производителя и потребителя и общественное благосостояние для монополии и совершенной конкуренции.

# Проверки и ограничения
Проверки:
- отсутствуют рынки без `market_id`;
- цены и предельные издержки не могут быть отрицательными.

Ограничения:
- пропуски (кроме цены) не учитываются;
- дубликаты удаляются.
